# EPOLISI assist

Свой собственный инструмент удалённого доступа (как AnyDesk/Supremo/TeamViewer, но свой и
бесплатный): адресная книга компьютеров + просмотр и управление экраном + передача файлов +
синхронизация буфера обмена, без привязки к чужим облачным серверам.

## Из чего состоит

- **app.py** — сервер (чистый Python 3, без внешних зависимостей): веб-консоль (адресная
  книга, помощники, доступ по филиалам, журнал подключений) и relay по WebSocket между
  оператором и агентом.
- **agent/** — программа для компьютера, к которому подключаются (Windows, C#/.NET
  WinForms). Собирается встроенным в Windows компилятором `csc.exe` — ничего ставить не
  нужно, см. `agent/build.ps1`.
- **operator/** — отдельное Windows-приложение для оператора (замена браузеру, когда
  антивирус/VPN мешают работе WebSocket в браузере). См. `operator/build.ps1`.

## Возможности

- Подключение без пароля на лету (akey) для «своих» компьютеров, с обязательным видимым
  уведомлением на экране агента во время сеанса — скрытого режима слежки нет и не будет.
- Несколько операторов могут одновременно смотреть один экран; управляет только один
  («Взять управление»).
- Помощники (отдельные логины) с доступом по конкретному компьютеру или сразу по филиалу.
- Журнал подключений (1 год, самоочистка) со счётчиком реальных кликов/нажатий — удобно для
  диагностики «подключился, но управление не работает».
- Передача файлов и синхронизация буфера обмена между оператором и агентом.
- Пароли на сервере хранятся хешированными (PBKDF2).

## Развёртывание

1. Перенести `app.py` на сервер (Linux), Python 3 из коробки.
2. Запускать как systemd `--user` сервис (пример в `epolisi-assist.service`).
3. Открыть порт наружу самостоятельно (например, через Cloudflare Tunnel) — в коде сервера
   жёстко прописанных облачных адресов нет.
4. Собрать `agent/EPOLISI-assist.exe` через `agent/build.ps1` и раздать компьютерам, к
   которым нужен доступ.
5. (Опционально) собрать `operator/EPOLISI-operator.exe` для операторов, которым не
   подходит браузер.
